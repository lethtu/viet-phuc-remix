# VIỆT PHỤC REMIX: HỒN CỔ NHỊP THỞ GEN Z
### Dự án Đề thi Audition: Phối trang phục truyền thống theo phong cách Gen Z

Ứng dụng web tương tác thế hệ mới kết hợp giữa **Storytelling di sản ngàn năm**, **Phòng thử đồ 3D tương tác 360 độ (Three.js)**, **Radar kiểm soát chuẩn mực văn hóa (Cultural Guard)**, **Phân tích hài hòa Ngũ Hành** và **Trình xuất Lookbook Tạp chí thời trang cao cấp**.

---

## 🌟 Tính Năng Nổi Bật

### 1. Giao Diện Landing & Storytelling ("Hành Trình Di Sản")
- Trải nghiệm dẫn dắt cốt truyện qua 5 thời kỳ lịch sử:
  - **Chương I**: *Ngàn Năm Hồn Đất & Tơ Tằm* (Áo Giao Lĩnh Lý - Trần - Lê & Áo Tứ Thân Kinh Bắc).
  - **Chương II**: *Đại Cải Cách 1744 & 1836* (Chúa Nguyễn Phúc Khoát, Vua Minh Mạng và sự ra đời của Áo Ngũ Thân).
  - **Chương III**: *Sắc Phục Cung Đình Vàng Son* (Áo Tấc & Nhật Bình Hoàng Triều, dải Ngũ Hành Thủy Ba).
  - **Chương IV**: *Gió Mới Đầu Thế Kỷ XX* (Cách tân Lemur Cát Tường đến Áo Dài hiện đại).
  - **Chương V**: *Việt Phục Remix 2026* (Gen Z tự tin mang di sản xuống phố).
- Tích hợp **Nhạc nền Cổ Phong Lofi** phát qua Web Audio API (âm hưởng thang âm ngũ cung Hò - Xự - Xang - Xê - Cống và sáo trúc thư thái).

### 2. Phòng Thử Đồ 3D Tương Tác (3D Mix & Match Studio)
- **Mannequin 3D tương tác trực quan**:
  - Xoay 360 độ mượt mà bằng kéo chuột hoặc cảm ứng trên điện thoại.
  - Phóng to/thu nhỏ, chuyển đổi các góc nhìn camera: *Toàn thân*, *Cận cảnh cổ áo & cúc ngũ thường*, *Mấn & phụ kiện*.
  - 4 Chế độ ánh sáng Studio chân thực:
    - ☀️ **Studio Runway**: Ánh sáng sàn diễn chuyên nghiệp.
    - 🏮 **Phố Cổ Hội An**: Đèn lồng vàng ấm lung linh hoài niệm.
    - 🌆 **Hoàng Hôn Cố Đô Huế**: Ánh tím đỏ cung đình lãng mạn.
    - ⚡ **Cyberpunk Sài Gòn Night**: Ánh neon cyan và hồng điện tử thời thượng.
- **Hệ thống phục trang & phụ kiện modul phong phú**:
  - *Áo chính*: Áo Ngũ Thân Tay Chẽn, Áo Tấc Đại Lễ, Áo Nhật Bình Cung Đình, Áo Tứ Thân Kinh Bắc, Áo Giao Lĩnh Cổ Phong, Áo Dài Cách Tân Gen Z.
  - *Lớp phối ngoài*: Áo khoác Blazer Oversize, Áo đối khâm voan tơ bay bổng, Áo Bomber gấm dệt rồng phượng.
  - *Trang phục dưới*: Quần lụa ống suông truyền thống, Quần Cargo túi hộp Streetwear, Quần Jeans rách bụi bặm, Chân váy tennis pleated.
  - *Phụ kiện đầu*: Mấn cuốn lụa, Mấn đính ngọc trai Y2K, Nón lá graffiti thư pháp, Kính râm Cyberpunk Neon Glow.
  - *Phụ kiện thân*: Kiềng bạc chạm hoa sen lồng xích Cuban hip-hop, Quạt xếp lụa vẽ thủy mặc, Túi đeo chéo phản quang, Tai nghe over-ear retro.
  - *Giày dép*: Guốc mộc quai nhung hoa cúc, Sneaker Chunky Retro, Bốt da đùi cao cổ, Hài thêu mũi cong hoàng tộc.
- **Tùy biến bảng màu & hoa văn thời gian thực**:
  - Bảng màu truyền thống (*Đỏ son, Vàng hoàng kim, Xanh chàm, Tím Huế, Trắng lụa tơ tằm, Đen mực xạ*) và màu Gen Z (*Cyber Neon Lime, Hologram Violet, Cam cháy*).
  - Hoa văn PBR: Lụa trơn, Gấm vân mây, Hoa sen đương đại, Long phụng kim tuyến, Họa tiết Đông Sơn.

### 3. Radar Văn Hóa & Cultural Guard (Cảnh Báo Sai Lệch)
- Tự động quét outfit theo thời gian thực và chấm điểm **Cultural Respect Score (0 - 100%)**:
  - ⚠️ **Cảnh báo Đại Kỵ Vạt Áo**: Cài vạt sang trái (Tả Nhậm) chỉ dành cho người đã khuất; hệ thống phát chuông cảnh báo đỏ và cung cấp nút "Khắc Phục Ngay" về vạt Hữu Nhậm chuẩn mực.
  - ⚠️ **Cảnh báo Tôn Nghiêm Hoàng Cung**: Hướng dẫn khi phối Áo Nhật Bình hoặc Áo Tấc với váy ngắn hoặc bối cảnh thờ tự.
  - 🛡️ **Huy hiệu Chứng Nhận Di Sản (Heritage Badges)**: Biểu dương những sự kết hợp sáng tạo đỉnh cao như *Áo Ngũ Thân x Sneaker Chunky*, *Kiềng Bạc Hip-hop*.
  - 📖 **Từ điển Văn hóa Tích hợp**: Giải thích nguồn gốc lịch sử, ý nghĩa 5 cúc áo Ngũ Thường (Nhân, Lễ, Nghĩa, Trí, Tín) và dải ngũ sắc Nhật Bình.

### 4. Kiểm Tra Hài Hòa Màu Sắc (Ngũ Hành & Bánh Xe Màu)
- Phân tích tương sinh, tương khắc, tương hòa theo hệ **Kim - Mộc - Thủy - Hỏa - Thổ**.
- Chấm điểm **Color Harmony Score (0 - 100%)** và đưa ra lời khuyên từ Stylist thời trang.

### 5. AI Stylist Theo Sự Kiện & Thời Tiết
- Lựa chọn theo hoàn cảnh: *Đi học / Thuyết trình*, *Lễ Tết / Du xuân*, *Prom / Dạ hội*, *Kỷ yếu*, *Dạo phố cà phê*, *Đám cưới*.
- Lựa chọn thời tiết: *Nắng ấm*, *Thu mát*, *Đông lạnh*, *Mưa rào*.
- Nút **"Gợi Ý AI Remix"** tự động đề xuất trang phục chuẩn mực và cực chất.

### 6. So Sánh Hai Phương Án Phối (A/B Test Mode)
- Đặt cạnh nhau Phương án A và Phương án B để so sánh bảng màu, phụ kiện, điểm văn hóa và tính phù hợp.

### 7. Trình Tạo Lookbook Tạp Chí Thời Trang (Magazine Cover Export)
- Thiết kế bìa tạp chí phong cách **VOGUE VIỆT NAM**, **ELLE HERITAGE**, **CYBER VĂN HIẾN**.
- Tùy chỉnh tên tạp chí, tên bộ sưu tập, tên Stylist.
- Nút **Tải ảnh Lookbook PNG độ nét cao** với hiệu ứng pháo hoa ăn mừng và nút sao chép link chia sẻ.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Dự Án

### Yêu cầu môi trường
- Node.js >= 18.0.0
- npm >= 9.0.0

### Chạy ở chế độ Development (Cục bộ)
```bash
npm run dev
```
Mở trình duyệt tại `http://localhost:5173`.

### Build cho môi trường Production
```bash
npm run build
```
Thư mục xuất bản: `dist/`.

## 🌐 Hướng Dẫn Deploy Lên Vercel

### Cách 1: Triển khai trực tiếp qua Vercel CLI
```bash
npx vercel --prod
```

### Cách 2: Triển khai qua GitHub & Vercel Dashboard (Khuyên dùng)
1. Đẩy mã nguồn lên repository GitHub của bạn:
   ```bash
   git init
   git add .
   git commit -m "feat: Viet Phuc Remix initial release"
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. Đăng nhập [vercel.com](https://vercel.com) bằng tài khoản của bạn.
3. Nhấn **"Add New Project"** → Chọn Repository vừa tạo.
4. Framework Preset sẽ tự động nhận diện là **Vite**.
5. Nhấn **"Deploy"** — Dự án sẽ được build và online trong vòng 30 giây!
